## 2. 입주민 웹 (모바일 우선)

**진입 온보딩**: 로그인 화면 **회원가입 버튼** → 단지 선택(공개 단지 목록 — 단지별 가입 링크 `?t=`는 사전 선택 딥링크) → 이메일+비밀번호 가입 → **이메일 검증 메일** 확인(검증 전 로그인 불가) → 로그인 → **개인정보 동의**(목적별 필수/선택) → 성함·생년월일·동·호수 입력(**만 14세 미만 차단**) → 승인 대기 화면(소장 승인 전 기능 차단) → 승인 후 아래 탭 진입. 비밀번호 재설정('비밀번호 찾기')도 제공.

하단 탭 5개 + 비서 중심.

```text
입주민 앱
├── 🏠 홈
│   ├── 우리 단지 요약 (공지 N건, 처리중 민원, 이번달 관리비)
│   └── 바로가기 (비서 질문, 민원접수, 관리비)
├── 💬 AI 비서 (핵심)
│   ├── 자연어 질의 (스트리밍 응답)
│   ├── 응답 + 출처 카드(원문 링크) + 👍/👎
│   ├── 추천 질문 (주차/공사시간/반려동물 규정 …)
│   └── "담당자 연결" (신뢰도 낮음/요청 시)
├── 📢 공지
│   ├── 공지 목록 (상단 고정·말머리 배지)
│   └── 공지 상세 (첨부 다운로드)
├── 📝 민원·하자
│   ├── 접수 (사진 첨부, AI 카테고리 추천)
│   ├── 내 민원 목록 + 처리상태
│   └── 민원 상세 (타임라인)
├── 💰 관리비
│   ├── 이번달/추이 (그래프)
│   ├── 항목 상세 (확정 관리비 데이터)
│   └── "왜 올랐나요?" → AI 설명 (전월·평균 대비)
└── 👤 나
    ├── 내 활동 (질의·민원·피드백 이력)
    ├── 우리집 평면도 (본인 세대만, 장치 마커·팝업)
    ├── 알림함 (인앱, 읽음 배지)            ← 웹푸시 Phase 2
    ├── 세대/알림 설정
    ├── 개인정보 동의 관리
    └── 회원 탈퇴 / 로그아웃
```

> 검색형 답변은 비서에 일원화. 공지/민원/관리비 화면은 "조회"에 집중하고, 의문이 생기면 비서로 자연스럽게 유도(딥링크).

## 3. 관리자 웹 (데스크톱 우선)

좌측 사이드바 네비. **역할별 메뉴 가시성**을 우측에 표기.

> 모바일(≤768px)에서도 **조회 + 승인 액션**은 보장하고, 넓은 테이블은 카드 레이아웃으로 폴백한다.

```text
관리자 콘솔
├── 💬 AI 비서             [MANAGER] (H20 — 첫 진입 화면·구 대시보드 대체, [ADR-0028](adr/0028-admin-assistant-home.md))
│   ├── 좌: 어시스턴트 채팅 (입주민 AI 비서와 동일 코어 — @liviq/ui 공용 승격 · POST /admin/assistant/ask · 서버 복원 없음)
│   ├── 우: 민원현황 패널 (상태별 카운트 · 미배정/처리중 강조 · 최근 민원 목록 → 민원 관리 딥링크)
│   └── 진입 브리핑 (빈 대화일 때 프론트 자동 질의 1회 — 인사 + summarize_inquiries 근거 민원 요약·할 일. 발송 아님)
├── 📊 민원현황            [MANAGER] (H20 — 구 대시보드를 관리소 운영 그룹으로 이동·개명, AI 도우미 현황 위젯 삭제)
│                          오늘 할 일 · 민원 현황 분포 · 시설 상태 · 일일 토큰 예산
├── 🧊 트윈 대시보드        [MANAGER] (H9 — geometry 있는 단지만 노출(`/me`의 `has_twin`), 대시보드 바로 아래, [ADR-0019](adr/0019-complex-twin-3d.md))
│   ├── 현황 패널 (타일: 총세대·입주율·미처리민원·설비이상 + 최근민원 + 설비상태 — 기존 민원·시설 API 재사용)
│   ├── 3D 단지 뷰 (기본=deck.gl · 실사=VWorld/Cesium 토글 — 세대 폴리곤, 클릭=세대 상세)
│   ├── 상태 오버레이 토글 (입주·민원·관리비·설비(동 단위))
│   ├── 실사 3D 전용 컨트롤 (렌더 스타일 쉘/포인트/끄기 · 시점 단지고정/360°회전 · 렌더링 우리단지만 clip)
│   └── 세대 상세 패널 (세대원 명부 마스킹 표시·미종결 민원·당월 관리비)
│                        · geometry 업로드(units.json)는 **UI 없음**(H9-6에서 제거 — 초기 1회
│                          적재 후 재업로드 수요 없음). 엔드포인트·시드 스크립트는 유지
├── 🅿️ 주차장 대시보드      [MANAGER] (H9-5 — 트윈 대시보드 바로 아래, 지하주차장 배치도, 항상 노출)
│   ├── 현황 카드 (전체 면·주차·입주민·외부·빈자리 + 동별 주차 대수)
│   ├── SVG 배치도 (442면 · 동 footprint · 입주민 파랑/외부 주황 · 면 클릭→동/호 차량 or 외부 번호판·경과)
│   │                        · 기본은 전체 표시(스크롤 없음) · 줌 1×/1.5×/2×/3× · 확대 시 드래그 팬
│   ├── 동별 칩 (401~405동·외부 — 대수 표시 + 지도·목록 필터 토글)
│   └── 목록 보기 (주차 차량 표: 면·번호판·소속 동호/외부·경과 · 행 클릭→지도 포커스)
│                        · 점유=PG `parking_vehicles.spot_no`·`entry_at`(H16·ADR-0023 개정 — 시뮬 폐기, ★ 번호판 카메라 API 적재 교체 지점)
│                        · 차량 348대(번호판 봉투 암호화 `plate_enc`·동/호 매핑) 시드 · 입주민 도우미(/parking/resident)는 백로그
├── 🙋 주민 관리           [MANAGER] (H7-9 — 가입 승인에서 개편, 목록 위주)
│   ├── 요약 통계 (명부 총계·미가입·가입완료·전출후보·승인 대기)
│   ├── 가입 대기 (자동 대조 — 일치 배지·불일치 사유)
│   ├── 명부 목록 (동·호·성함 마스킹·상태·차량, 검색·필터·페이지네이션)
│   │                        · 차량은 parking_vehicles 정본 **조회 전용**(세대 단위·관리자 평문, H9-6)
│   │                          — 입력·수정은 주차 도메인, 명부 엑셀 양식에 차량 없음
│   └── 명부 엑셀 업로드 (접이식 + 마지막 업로드 일시·건수·오류 상시)
├── 📝 민원 관리           [MANAGER STAFF]
│   ├── 접수함 (AI 분류·우선순위)
│   ├── 배정/처리
│   └── 처리 통계
├── 📢 공지사항             [MANAGER STAFF]
│   ├── 공지 목록 (고정·상태 배지: 임시저장/예약/발행)
│   ├── 작성 (제목·본문·분류(NOTICE_CATEGORY 코드 선택)·행사/작업 기간·대상 동·키워드·대상·첨부 업로드)
│   ├── 수정 / 삭제 · 상단 고정
│   └── 임시저장 / 예약 발행 (예약 시각 도달 시 자동 발행)
├── 📄 문서 관리           [MANAGER STAFF]
│   ├── 업로드 (PDF/HWP/이미지 · 카테고리(DOC_CATEGORY 코드 선택, 필수))
│   ├── 공개범위 설정 (ALL/RESIDENT/ADMIN)
│   ├── 문서 검색 (자연어 → 원문 발췌·링크)
│   └── 색인 상태 (pending/indexed/failed, 재색인)
├── 💰 관리비 관리          [MANAGER]
│   ├── 엑셀 업로드 (검증·오류 리포트·미리보기·확정)   ← 같은 월 재업로드=전체 교체
│   ├── 월별 부과 현황
│   └── 세대별 조회
├── 🔧 시설 관리           [MANAGER] (H13 — 메인을 3D 시설 그래프로 개편, [ADR-0022](adr/0022-facility-graph-dashboard.md))
│   ├── **시설 그래프 (메인)** — 3D force-directed(설비·장애·정비 노드 + HAS_INCIDENT·HAS_MAINTENANCE)
│   │   ├── 렌즈 토글 (계통별=facilities.type 기본 · 위치별=동 단위, H13-2)
│   │   ├── 검색 → 카메라 fly-to 강조 (3D 겹침 완화의 필수 경로)
│   │   └── 상세 패널 (현황 normal/check/fault/risk · 정비 이력 · 고장 이력 · 관련 민원(정식/추정 배지))
│   ├── 목록 보기 (보조 뷰 토글 — 설비 상태 목록·등록/장애/정비 다이얼로그·유지보수/장애 이력)
│   │                        · 3D 캔버스의 **접근성 대체 수단**(스크린리더·키보드 — [05 §5](05-ui-ux-design.md))
│   └── 시설 AI 도우미 (유사 장애 검색→원인 후보)
├── 👥 직원 관리           [MANAGER] (STAFF 초대 링크 메일·비활성화·삭제, 타 소장 삭제 — H7-5 최상위 승격·H7-6 수명주기)
└── ⚙️ 설정               [MANAGER] (H8-4·H8-5 — [ADR-0017](adr/0017-tenant-code-registry.md))
    ├── ⚙️ 코드 관리         [MANAGER] (H8-4 — 그룹 선택 → 코드 트리: 추가·수정·정렬·비활성·삭제, is_system 그룹 잠금)
    ├── 🏠 동/호수 관리      [MANAGER] (H8-5 — 동 CRUD·세대 목록·층/호 범위 일괄 생성·개별 삭제)
    │                        · 삭제 보호: 입주민·명부·민원·관리비 연결 세대/세대 보유 동은 삭제 불가(409)
    │                        · 초기 대량 등록은 seed_households_xlsx.py 스크립트 유지
    │                        · H9-6: 호수 옆 평면도 타입 표시 `201호(84M)` — 트윈 units.json
    │                          업로드 산물(household_geometries)을 읽기만 함(마스터·수동 지정 없음)
    └── (Phase 2 — 민원 카테고리·SLA, ERP 연동 상태, 개인정보/보관정책)
```

> **SYS_ADMIN 뷰(web-admin 내)**: SYS_ADMIN 로그인 시 위 소장 메뉴 대신 **단지 관리** 전용 뷰만 노출 — 단지 생성·소장 초대(단지당 1명)·소장 제거·빈 단지 삭제·단지 비활성화/재활성화(단지 콘텐츠 비열람, H7-6). **AI 설정**(H15-1·H15-3): LLM 백엔드 접속 정보(base URL·모델·API 키·reasoning effort) + 임베딩 백엔드(차원 1024 고정·재색인 버튼) + 튜닝 노브(top_k·출력 상한·timeout·confidence·캐시 TTL)를 UI에서 편집·저장·연결 테스트 — 전역 설정이라 SYS_ADMIN 전용([03 §4.7](03-database-design.md) `ai_backend_config`).
> **Phase 2**: 입대의·선관위 전용 게시판·안건은 Phase 2. MVP의 회의록은 문서 관리(DOC_CATEGORY 코드 "회의록")로 업로드·열람.
